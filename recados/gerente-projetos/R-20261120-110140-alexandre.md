  - nunca chassi, cor, município, UF, data ou dados de dono;

- **Onde:** armazenamento persistente do Render Pro (disco persistente ou banco do próprio Render). O gerente propõe e diz o que é governança (render.yaml).
- **Como funciona:**
  - a placa já guardada responde sem chamar a API;
  - a placa nova chama a API uma vez e fica guardada;
  - a placa que a API diz não existir não é chamada de novo no mesmo dia.
- **LGPD:** o gerente diz como fica a guarda (o que é guardado, quem acessa, se há prazo para apagar). Não se acrescenta nada além do pedido do Alexandre sem ele decidir.
